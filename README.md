# CST4125 Blockchain Development

Hardhat project for the CW1/CW2 campus event credits and ticketing coursework.

## Current stage

- base Hardhat scaffold initialized
- sample `Counter` contract still present
- coursework contracts will be added step by step from this starting point

## Planned contract set

- `CreditsToken`
  - ERC-20 platform credits
- `TicketNFT`
  - ERC-721 non-transferable tickets
- `TreasuryVault`
  - event-level paid/refund accounting
- `EventPlatform`
  - organizer approval, event setup, ticket sales, and check-in flow

## Commands

```bash
npx hardhat compile
npx hardhat test
```
